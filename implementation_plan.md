# Implementation Plan: The Alpha Beauty Platform

A high-end, luxury reservation and management platform for "The Alpha Beauty" salon.

## 1. Design System (Luxury & Premium)
- **Primary Palette**: Deep Charcoal (#121212), Pearl Gold (#D4AF37), Champagne (#F7E7CE).
- **Typography**:
  - Headings: 'Playfair Display' or 'Bodoni' (Classic elegance)
  - Body: 'Inter' or 'Montserrat' (Modern readability)
- **Components**: Glassmorphism effects, smooth gold gradients, and subtle floral/ornamental micro-animations.

## 2. Feature Roadmap
### Phase 1: Brand Presence & Discovery
- [ ] **Home Page**: Hero section with video/high-quality image background, salon motto.
- [ ] **Service Catalog**: Elegant grid of treatments with pricing and descriptions.
- [ ] **Digital Gallery**: High-resolution showcase of salon work.

### Phase 3: Core Functionality (Supabase)
- [ ] **Booking Engine**: Real-time availability calendar, therapist selection, and deposit payments.
- [ ] **Client Portal**: User accounts for history, upcoming appointments, and loyalty points.
- [ ] **Admin Dashboard**: Appointment management, staff scheduling, and analytics.

### Phase 4: Growth & Engagement
- [ ] **Affiliate Program**: Referral tracking and reward system for clients.
- [ ] **Feedback System**: Post-service reviews and ratings.

## 3. Technical Stack
- **Frontend**: Vite + React
- **Styling**: Vanilla CSS (CSS Modules or Global CSS variables)
- **Backend**: Supabase (Auth, Database, Edge Functions)
- **Hosting**: Netlify

## 4. Immediate Next Steps
1. Initialize Vite project.
2. Define Global CSS Design Tokens.
3. Build the Hero and Service Catalog sections.
